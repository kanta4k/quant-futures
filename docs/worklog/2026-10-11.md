## 3. 포트폴리오 백테스트 (커밋 `54ec986`)

- 여러 종목을 한 계좌로 시뮬레이션. 주문별·전체 위험, 종목·총·순 익스포저, 증거금, 상관 그룹(|ρ| ≥ 0.8) 한도 적용. 신호를 건너뛴 사유 집계
- 동적 유니버스: 매일 직전 7일 거래대금 상위 K (데이터가 덜 찬 신규 상장 제외)
- 학습/검증/최종 평가 구간 분리 (각 구간을 새 계좌로 실행)
- 파라미터 그리드 탐색 (최대 200조합, 검증 점수로만 순위, 최종 평가 구간은 사용 안 함)
- 대시보드: 후보 풀 일괄 수집, 구간별 결과표, 구간 색칠 자산 곡선, 종목별 성과, 탐색 화면

참고 결과 (기본 파라미터, 15종목 풀에서 상위 5): 학습 −3.6% / 검증 −4.7% / 최종 −2.2%. 탐색 1위 조합은 검증 +13.3% → 최종 −0.1%로 과최적화가 확인됨. 전략 연구는 나중에 요청 시 일괄 진행하기로 함.
